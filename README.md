# Aarogya

A personalized AI-powered wellness companion.

## Stack

### Frontend
- Next.js
- React
- Tailwind CSS
- shadcn/ui
- Magic UI
- Lucide Icons

### Backend
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis
- Qdrant

### AI
- LangChain
- Gemini
- User-provided AI provider API keys
- RAG

### Infrastructure
- Docker
- Docker Compose

## Core product areas

- Authentication
- Personalized onboarding
- Dashboard
- Aaryu AI mentor
- Saved chat sessions
- Wellness roadmap generation
- Progress tracking
- Progress photography
- Account management
- AI provider settings
